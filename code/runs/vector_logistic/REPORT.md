# 第一轮：独立向量逻辑回归评分

## 研究问题与方法

只用每个候选的 1024 维固定向量，是否能超过答案多数投票？使用候选级二元逻辑回归：训练标签为官方解析的最终数值是否等于参考答案；允许一题多个正例。无法解析者为负例。训练集共有 4755 题、19020 个候选。每题预测时选择线性分数最高的候选，平分选较早候选。不使用投票、题目 ID、原始文本特征或参考答案推理。

训练集逐维标准化，方差下限 1e-6；均值和缩放折叠进导出系数。模型保留 1024 个权重和一个截距。CPU 全批量 Adam，学习率 0.03，种子 2026，L2 惩罚不包含截距。未声称训练达到数值收敛。

## 配置选择

预设 3 个 L2 强度 × 3 个训练轮次，选择依据为验证集题级选择准确率，相同则比较候选二元交叉熵。测试评分在 freeze.json 写出并验证后执行，不参与本轮参数选择。后续改进依据验证诊断。

| L2 | 训练轮次 | 验证正确数 | 验证准确率 |
|---|---:|---:|---:|
| 0.0001 | 40 | 712/798 | 89.22% |
| 0.0001 | 80 | 712/798 | 89.22% |
| 0.0001 | 120 | 713/798 | 89.35% |
| 0.001 | 40 | 710/798 | 88.97% |
| 0.001 | 80 | 711/798 | 89.10% |
| 0.001 | 120 | 713/798 | 89.35% |
| 0.01 | 40 | 711/798 | 89.10% |
| 0.01 | 80 | 714/798 | 89.47% |
| 0.01 | 120 | 716/798 | 89.72% |

选定 L2=0.01，120 轮。训练搜索内部计时 4.388 秒，包含数据加载、三次训练和验证比较；不含 Python 启动及导入。仅一个种子，未进行跨种子或交叉验证，因此这是初步实验证据。

## 官方成绩

| 方法 | 验证集 | 测试集 |
|---|---:|---:|
| 多数投票 | 688/798（86.22%） | 323/467（69.16%） |

相对基线，验证提高 3.51 个百分点，测试提高 7.49 个百分点。测试官方 accuracy 为 76.65952890792292。

## 验证集错误变化

| 分组 | 题数 | 基线正确 | 向量正确 | 修正基线错误 | 破坏基线正确 |
|---|---:|---:|---:|---:|---:|
| all | 798 | 688 | 716 | 68 | 40 |
| answer_disagreement | 355 | 245 | 275 | 68 | 38 |
| tied_leaders | 88 | 38 | 56 | 36 | 18 |
| unique_leader | 710 | 650 | 660 | 32 | 22 |

答案分歧组准确率从 245/355=69.01% 提升到 275/355=77.46%；最高票平票组从 38/88=43.18% 提升到 56/88=63.64%。模型与投票有互补性：68 题得到修正，但40题被破坏，支持下一轮研究融合，不能只观察修正的错题。

只有一种可解析答案的443题，向量模型选错2题，因为当前模型不屏蔽官方无法解析的候选。这是验证集上的诊断发现；本轮保留纯向量模型，屏蔽规则应作为下一轮独立消融，而非悄悄加入当前模型。

## 置信度

候选级 Brier=0.1348，10箱 ECE=0.0226。它们是同一开发验证集上的描述性指标，不能当作独立校准测试。候选 sigmoid 分数并不等于每题被选答案正确的校准概率。

最高分与次高分的差距由低到高，四组准确率为 90.00%、90.50%、88.44%、89.95%，没有单调提高。因此不能直接认为“分差越大，选择就越可靠”。一题多个候选都正确时，小分差也可能是正常现象。

推理资产 model.npz+config.json 共 9717 字节（0.009267 MiB），小于16 MiB。源码、模型及配置 SHA256 见 freeze.json。源码位于 code/，资产和输出位于 runs/vector_logistic/。

从 code/ 运行：

~~~bat
conda activate mp1
set OMP_NUM_THREADS=4
set OPENBLAS_NUM_THREADS=4
set MKL_NUM_THREADS=4
python train_vector.py
python evaluate_vector.py
~~~

直接使用已训练资产复现，无须重训：

~~~bat
python predict.py --method vector_logistic.py --checkpoint runs/vector_logistic/model_bundle --split test --output runs/vector_logistic/vector/test-predictions.json
python score_predictions.py --split test --predictions runs/vector_logistic/vector/test-predictions.json --output runs/vector_logistic/vector/test-score.json
~~~

requirements-vector.txt 提供训练依赖约束；现有 mp1 已具备所需依赖，本轮未安装新包。若在新机器安装，先安装依赖；安装完成后预测和评分离线执行。
